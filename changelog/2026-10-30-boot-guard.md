Octatrack base (beta): if the Octatrack crashes or freezes while it loads your modules after switching on, the next start no longer does the same again. The module it was loading is left out and the rest load; the screen names it (for example TAPE ECHO LEFT OUT), and it stays out until your next sync. If the base cannot tell which module it was, or the unit hung twice in a row while starting, that one start loads no modules (MODULES HELD) and the next start tries them all again. Before, a module that crashed the unit at startup restarted it over and over until you held FUNC while switching on. Tested on the computer only (a crash, a DSP stall and a hang during the restore); not yet run on a unit.
